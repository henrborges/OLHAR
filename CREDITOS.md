# Créditos e dependências

## Projeto

Olhar — Fotografia com celular. Conteúdo educativo elaborado para o público
interno do Sebrae MT, com fundamentos, exercícios e Cobertura de Missões.
As referências de conteúdo estão em `content.json` e na página de referências
do ebook. Menus e recursos de câmera variam conforme o aparelho.

## Dependências entregues no pacote

| Item | Uso | Arquivo de licença |
| --- | --- | --- |
| pdf-lib 1.17.1 | Montagem do PDF no navegador | `assets/licenses/pdf-lib-LICENSE.md` |
| DM Sans | Tipografia local | `assets/licenses/DM-Sans-OFL.txt` |
| Manrope | Tipografia local | `assets/licenses/Manrope-OFL.txt` |

Os arquivos dessas dependências e suas licenças acompanham o pacote. Não há
carregamento de fontes ou bibliotecas a partir de CDN durante o uso do portal.
As bibliotecas Python de manutenção são descritas em `tools/requirements.txt`.

## Demonstrações

Ilustrações SVG, comparações de enquadramento e vídeos foram preparados para
este material. As interfaces são esquemáticas e não reproduzem um modelo
específico de celular. O exemplo de insight no módulo de Missões é fictício.
